# Iris Flower Classification

## OIBSIP Data Science Task 1

### Objective

The objective of this project is to build a machine learning classification model that predicts the species of an Iris flower based on its physical measurements.

The model classifies flowers into three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

## Dataset

The Iris dataset contains measurements of Iris flowers, including:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The target variable is the Iris flower species.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Steps Performed

1. Loaded the Iris dataset.
2. Inspected the dataset structure and dimensions.
3. Checked for missing values.
4. Performed exploratory data analysis.
5. Visualized relationships between the flower measurements.
6. Analyzed the distribution of the Iris species.
7. Prepared the input features and target variable.
8. Split the dataset into training and testing sets.
9. Trained a machine learning classification model.
10. Made predictions on the test data.
11. Evaluated the model using classification metrics.
12. Analyzed the model's performance using a confusion matrix.
13. Tested the model on new flower measurements.

## Machine Learning Approach

The project uses supervised machine learning because the dataset contains labelled examples of Iris flowers.

The input features are:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

The output is the predicted Iris species.

## Results

The trained classification model successfully learned the relationship between flower measurements and Iris species and was evaluated using the test dataset.

The notebook contains the detailed analysis, visualizations, model training process, evaluation results, and predictions.
